# Ansible Role: install_docker

Данная роль устанавливает Docker CE (Community Edition) и плагин Docker Compose v2 в системах на базе Debian (Debian, Ubuntu).

## Логика работы

Роль выполняет следующие действия:
1.  **Очистка:** Удаляет любые ранее настроенные официальные APT-репозитории и GPG-ключи Docker для обеспечения чистого состояния.
2.  **Установка зависимостей:** Устанавливает необходимые пакеты, такие как `ca-certificates` и `curl`.
3.  **Добавление GPG-ключа:** Загружает и добавляет официальный GPG-ключ Docker в `/etc/apt/keyrings`.
4.  **Добавление APT-репозитория:** Добавляет официальный APT-репозиторий Docker в источники системы.
5.  **Установка Docker:** Устанавливает пакеты `docker-ce`, `docker-ce-cli`, `containerd.io` и `docker-compose-plugin`.
6.  **Запуск службы:** Гарантирует, что служба `docker` запущена и включена для автозагрузки.

## Требования

-   Целевой хост должен быть системой на базе Debian (например, Ubuntu).

## Переменные

Эта роль использует переменные, определенные в `defaults/main.yml`, для управления именами пакетов и контрольными суммами. Как правило, они стабильны и не требуют переопределения.

## Зависимости

Нет.
